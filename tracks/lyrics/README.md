# Lyrics

One sheet per track, named after the MP3: `Artist - Title.lrc` for
`Artist - Title.mp3`. Plain text works; timestamps make the player follow
along. The format and an example are in [../README.md](../README.md).

Send your own only. These are the words the artist wrote, so they arrive from
the artist, in the same pull request as the track or a later one.
